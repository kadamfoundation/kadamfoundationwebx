# Source Image Archive

This folder keeps original uploads, alternate image candidates, and screenshots
for reference. These files are not served by the website. Approved production
images belong in `public/images/`; see [its image guide](../../public/images/README.md).

## Folders

- `events/`: original Youth Parliament and Artelle event posters.
- `partners/`: original partner logo uploads.
- `programs/`: original Project Samanvay images and logo.
- `screenshots/`: UI screenshots used for review and layout feedback.
- `social/`: original thumbnails used for the Instagram Reel cards.
- `team/`: original city-head photos corresponding to active team portraits.
- `unreviewed/gallery/`: unused gallery image candidates; review before publishing.
- `unreviewed/numbered-uploads/`: photos with numbered filenames; identify before use.
- `unreviewed/programs/`: unused program image candidates; review before publishing.
- `unreviewed/whatsapp-uploads/`: undetermined WhatsApp uploads; identify before use.

Keep the original files here when creating a web-ready image. Do not publish
items from `unreviewed/` without reviewing their content, approval, and intended
use. When adding an approved image to the website, use a descriptive filename
and update the relevant page or data reference.
